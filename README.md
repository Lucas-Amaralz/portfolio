# The City

Portfólio jogável de Lucas Nunes Amaral, Analista de Infraestrutura Júnior.

Uma cidade em pixel art para explorar: cada bairro guarda uma parte do currículo.

- **Currículo**: o telão no centro da cidade
- **Projetos**: a loja com a vitrine dos projetos
- **Experiência**: a Trilha da Carreira, um prédio por emprego
- **Certificações**: o farol
- **Contato**: a torre de rádio

Acesse: https://lucas-amaralz.github.io/portfolio/

## Pastas

- Raiz: o jogo pronto, publicado pelo GitHub Pages.
- `codigo-fonte/`: o código do jogo (Phaser 3, TypeScript e Vite). Para rodar: `npm install` e `npm run dev`.
- `ultima-luz/`: "Última Luz Acesa", o primeiro portfólio jogável (HTML, CSS e JavaScript puro), protótipo antes da cidade.
- `curriculo.pdf`: o currículo.
